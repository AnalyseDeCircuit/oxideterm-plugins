# 证书查看器

在本地文件管理器或 SFTP 的文件预览中打开 PEM、DER、CRT、CER。左侧选择文件内的证书，右侧显示基本信息与详细字段，可复制字段值。

显示主体、签发者、有效期、备用域名/IP、密钥用途、算法标识、序列号、扩展 OID 及 SHA-256/SHA-1 指纹。文件内最多 64 张证书，文件上限 10 MiB。

只解析用户选择的文件。有效期状态不代表系统信任、证书链正确、签名已验证或未被吊销；这些状态明确标为未检查。不会访问系统证书库或查询网络。PEM 中只解码 CERTIFICATE 块，其他块（包括私钥）不进入结果；原始输入由零化缓冲区持有。DER 支持单张及连续的证书，格式错误时拒绝解析。P12/PFX 暂不支持，不会请求密码。

## 构建与试用

在市场仓库根目录执行：

```sh
node scripts/build-inspection-plugin.mjs certificate-preview --local
node scripts/verify-inspection-plugin.mjs certificate-preview --local
```

运行时是独立原生程序，无需 Node.js 或系统解析工具；Node.js 仅用于构建和打包。正式兼容范围为 `>2.2.0`；本地包用于已重新编译检查器预览接口、但仍标为 2.2.0 的应用，不可上架。去掉 `--local` 构建正式包。发布工具自动将此插件归入“预览”分类。六平台工作流分别构建并验证资产，不自动发布。
