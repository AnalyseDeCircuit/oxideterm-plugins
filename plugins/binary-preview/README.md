# 二进制检查器

从文件预览入口检查 ELF、Mach-O、PE；没有扩展名的程序也按文件头识别。界面提供概览、节区和十六进制三个视图。

显示架构、位数、字节序、入口虚拟地址、文件大小和整个文件的 SHA-256。Mach-O 通用二进制支持选择架构；LC_MAIN 文件偏移会转换为虚拟入口地址，并额外显示整个文件的入口偏移。节区偏移也相对于整个文件计算；没有落盘数据的节区不可跳转。

点击节区偏移进入十六进制视图，或输入十进制/0x 十六进制偏移。复用宿主十六进制格式化和原生只读编辑器，每次读取 512 字节。未知 .bin 文件仍可看指纹和原始字节。没有编辑、执行或反汇编功能。文件上限 10 MiB、64 个架构和 1024 个节区。

## 构建与试用

在市场仓库根目录执行：

```sh
node scripts/build-inspection-plugin.mjs binary-preview --local
node scripts/verify-inspection-plugin.mjs binary-preview --local
```

运行时是独立原生程序，无需 Node.js 或系统解析工具；Node.js 仅用于构建和打包。正式兼容范围为 `>2.2.0`；本地包用于已重新编译检查器预览接口、但仍标为 2.2.0 的应用，不可上架。去掉 `--local` 构建正式包。发布工具自动将此插件归入“预览”分类。六平台工作流分别构建并验证资产，不自动发布。
