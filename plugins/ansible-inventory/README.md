# Ansible 主机清单

从Ansible 清单发现主机，在原生连接表单中检查地址、补充认证，再连接或保存。只注册标签页。

## 使用

需要 Node.js 22 或更新版本，以及已安装的 Ansible（提供 ansible-inventory 命令）。当前使用 Unix 启动器，面向 macOS 和 Linux。

1. 安装并启用插件，打开其标签页。
2. 填写客户端命令或完整路径，以及清单文件或目录路径。
3. 点击“发现主机”，搜索后点击“配置连接”。
4. 在应用原生表单中检查信息，配置认证和跳板机后连接或保存。

读取调用 `ansible-inventory --list -i <绝对路径>`，由 Ansible 处理 INI、YAML、变量继承及动态清单。动态来源可能运行本地代码，因此启用插件不会自动读取。只提取 SSH 主机的名称、地址、端口、用户和分组，跳过非 SSH 连接及未解析的模板值。多个分组按名称排序后选第一个；不导入密码、密钥、代理命令或其他变量。

来源刷新不会自动修改已有连接。读取超时为 4 秒，输出上限为 8 MiB，最多 5000 台主机，每页显示 20 台。刷新失败清除旧结果。客户端退出信息和原始输出不写入日志、设置或宿主界面。关闭插件会终止读取任务；独立守护进程通过管道关闭检测宿主强制结束的情况。输入位置只保留在本次插件进程内。

## 构建与验证

在市场仓库根目录执行：

```sh
node scripts/build-host-source.mjs ansible-inventory --package
node --test scripts/host-sources.test.mjs
```

公共界面和进程管理源码位于 `packages/host-sources/`，构建时复制到包内，运行不依赖源码仓库。业务解析器位于本插件的 `source.cjs`。包含 11 种界面语言。

正式兼容范围为 `>2.2.0`，需要新增的 `connections.openForm` 接口。若本地主程序仍标为 2.2.0，但已编译该接口，可给构建命令追加 `--local` 生成本地试用包；插件仍会检查接口是否存在。这些试用包不能上架。
