# OxideTerm 背景素材包

**简体中文** | [English](README.en.md)

两段为 OxideTerm 原创的动态背景：晨雾使用暖白与青绿，夜流使用深蓝与淡紫。曲面与反光缓慢起伏，渐变柔和，适合浅色和深色外观。素材包只提供视频，不运行插件代码，也不需要额外权限。

双背景包已撤回并删除。请分别选择 Dawn Mist（晨雾）、Night Flow（夜流）或 Desert Gold（沙漠金），每个插件只包含一张背景，独立下载和更新。此目录的制作、校验与打包脚本仍由各独立背景复用。

| 素材 | 文件 | 规格 |
| --- | --- | --- |
| 晨雾 | `assets/oxide-dawn-mist-4k-v1.mp4` | 3840 × 2160，24 帧/秒，16 秒循环 |
| 夜流 | `assets/oxide-night-flow-4k-v1.mp4` | 3840 × 2160，24 帧/秒，16 秒循环 |

两段视频从生成阶段以 4K 绘制，使用 H.264、8 位 YUV 4:2:0 色彩，不含声音。光线和运动在一个周期内循环，不使用外部图片或视频。

## 安装和选择

1. 在“设置 → 外观”的素材库点击“获取更多背景”，进入插件市场的“背景素材”分类。
2. 安装 OxideTerm Backgrounds，然后返回素材库选择视频。
3. 使用跟随系统外观时，分别为浅色和深色外观选择背景。

安装不会改变当前主题或背景。素材复制到当前设置文件所在目录的 `backgrounds` 文件夹；便携版使用自己的数据目录。卸载素材包后，已导入的视频仍在素材库中，可以通过素材卡片删除。

已发布的 OxideTerm 2.2.2 尚不支持背景素材包。此包需要后续包含该功能的版本，兼容范围为 `>2.2.2`。

## 播放分辨率

视频保留 4K 母片，播放器按现有设置缩放。宽高上限留空使用自动模式；也可以设置为 3840 × 2160、2560 × 1440 或 1920 × 1080。素材库缩略图使用现有小尺寸预览，无需另装低分辨率版本。

## 生成和打包

安装 NumPy、Pillow 和包含 libx264 的 FFmpeg 后，在本目录运行：

```bash
python3 scripts/generate.py
npm run check
npm run package:unix
```

Windows 可使用 `npm run package:windows`。生成工具只用于制作素材，播放时不需要这些工具。校验命令会检查实际视频的尺寸、编码、时长、帧率和音轨。

`--preview-only` 只生成各阶段的预览图；`--scene dawn-mist` 或 `--scene night-flow` 可以单独重做一段视频。生成时会显示帧数、速度和预计剩余时间，完整编码成功后才替换正式素材。

发行包为一个跨平台 ZIP，视频保留在清单声明的 `assets/` 路径。发布工作流复用仓库现有的发行记录生成和市场同步流程；发布标签为 `backgrounds-v1.0.0`。
