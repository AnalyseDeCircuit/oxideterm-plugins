# 晨雾

**简体中文** | [English](README.en.md)

暖白与青绿曲面缓慢起伏的原创动态背景，适合浅色外观。本插件只提供这一张背景的视频素材，不运行代码，也不需要额外权限。

## 素材规格

- 文件：`assets/oxide-dawn-mist-4k-v1.mp4`
- 分辨率：3840 × 2160；24 帧/秒；16 秒循环。
- 编码：H.264、8 位 YUV 4:2:0，无声音。
- 原生 4K 绘制，播放器可按自动模式或用户指定尺寸降采样。

## 安装与使用

需要 OxideTerm 2.2.3 或更高版本。在“设置 → 外观 → 获取更多背景”打开插件市场，安装 Dawn Mist，再返回素材库选择晨雾。

安装不会改变当前外观。素材导入当前配置的数据目录，便携版使用自己的数据目录；卸载插件后已导入的视频仍保留，可在素材库单独删除。已安装旧双背景包的用户无须重复安装同一张背景。

## 制作与发布

在本目录运行 `npm run check` 检查实际视频，使用 `npm run package:unix` 或 `npm run package:windows` 生成只含这一张背景的跨平台 ZIP。各背景拥有独立插件标识和版本，发行标签为 `background-dawn-mist-v1.0.0`。
