# SQLite 预览

从本地文件管理器和 SFTP 的文件预览入口打开 SQLite 数据库。复用应用原生表格，左侧选择数据表，右侧每页显示 50 行。

支持 `.sqlite`、`.sqlite3`、`.db` 和 `.db3`；后两种会先检查 SQLite 文件头。首版预览限制为 10 MiB、256 张普通表、每表 64 列。长文本最多显示 256 个字符，二进制值显示前 128 字节的十六进制，截断处有省略号。保留 NULL 与空字符串的区别。

插件以只读连接打开数据库，不执行用户 SQL，不创建、修复或迁移数据库。只展示普通表；视图、虚拟表、内部表不执行或展示。本地数据库支持 SQLite 正常的 WAL 读取；SFTP 只能下载主文件，因此遇到非空 WAL/回滚日志或下载期间文件变化时拒绝预览。远程文件请使用停止写入后的完整备份，不用于在线数据库的一致性备份。表数据可能包含私人信息，只用于当前预览，不写入插件日志或设置。

正式包需要应用版本 `>2.2.0`，以及新增的表格预览接口。本地应用仍为 2.2.0 时可用 `node scripts/build.mjs --local` 生成专用包，但仍须先编译当前宿主代码。无需系统安装 SQLite、Node.js 或额外数据库服务即可运行插件。

## 构建

在本插件目录运行：

```sh
cargo generate-lockfile # 仅首次创建或主动更新依赖时
node scripts/build.mjs
node scripts/verify-package.mjs
```

构建脚本需要 Node.js 和市场仓库的 npm 依赖；运行插件本身不需要。六平台工作流使用原生运行器分别构建并测试解压后的资产。不会自动上架。

插件代码使用 MIT 许可证；打包的 SQLite 引擎属于公共领域。
