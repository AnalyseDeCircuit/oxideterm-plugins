# 小工具箱

独立更新的本地文本处理插件，提供六组工具：

- 编码：Base64、URL 组成部分、文本与十六进制互转。
- JSON：格式化、压缩、校验、按路径提取字段。
- 时间：秒／毫秒时间戳与日期互转，按地区名称转换时区。
- 文本：保序去重、升降序排列、清除 ANSI 控制符、正则提取。
- 摘要：原始 UTF-8 文本的 SHA-256、SHA-512。
- 生成：UUID v4，以及指定长度的字母数字、十六进制或纯数字随机字符串。

点击左侧扳手图标打开或切回工具箱标签页，也可在终端选中文字后选择“在工具箱中处理…”。不注册独立侧栏面板。输入和结果复用应用原生编辑器；结果只读，可复制、清空或用作下一次输入。窄窗口自动上下排列。输入只保留在当前标签页，关闭标签页后释放；不保存处理历史，不自动发送结果到终端。

- Base64 严格检查字符、填充和长度；解码结果必须是有效的 UTF-8 文本，不会丢弃无效字节。保留空格和原始换行。
- JSON 保留大整数及高精度小数，错误显示行和列。校验成功时原样返回输入。
- 字段提取使用 JSON Pointer，例如 `/items/0/name`。空路径表示整个文档；字段名中的 `~` 写作 `~0`，`/` 写作 `~1`。
- 每次处理最多 256 KiB 输入、4 KiB 路径和 2 MiB 输出；执行失败保留原文和上一次结果。
- 时间戳须明确选择秒或毫秒；日期采用带偏移的 ISO 格式，例如 `2026-10-05T12:00:00+08:00`。地区时区使用 `Asia/Shanghai`、`UTC` 等名称。不会猜测单位，也不会静默截断小数秒。
- 按行整理沿用首个换行样式并保留末尾换行；排序区分大小写。正则逐行输出完整、不重叠的匹配，最多 10,000 个，可用 `(?i)`、`(?m)` 等标志。
- 随机字符串长度为 1–4096；由系统安全随机源提供字节，字符选择使用拒绝采样以避免偏差。随机源失败时直接报错。

采用 Rust WASM 与宿主原生界面，一个安装包可用于六个平台。运行时不需要 Node.js，不申请文件、网络或剪贴板读取权限。仅在点击复制时由宿主写入剪贴板。11 种语言随插件分发。

## 构建与检查

安装 Rust 的 `wasm32-wasip1` 目标和 Node.js 22。在市场仓库执行：

```sh
cargo test --manifest-path plugins/toolbox/Cargo.toml --locked
node scripts/release-plugin.mjs prepare plugins/toolbox
node plugins/toolbox/scripts/package.mjs --local
```

打包自动验证实际 WASM 的注册、选区入口、连续处理和语言键集合。省略 `--local` 生成正式包。
正式包要求 `>2.2.0`。本地试用包可安装到仍标为 2.2.0、但已重新编译新文本工作区控件的应用，不能上架。

此插件只处理文本，不读取文件或执行文件操作。
