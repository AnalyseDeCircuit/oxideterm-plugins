# Plugin Marketplace

- For plugin creation, release preparation, catalog versions, compatibility corrections, or publishing workflow changes, use [oxideterm-plugin-release](.agents/skills/oxideterm-plugin-release/SKILL.md).
- Keep the scripts and [publishing guide](docs/PUBLISHING.md) as the maintained procedure; use the release automation instead of assembling release records manually.
- Changes to documentation or styling alone do not require a plugin release. Preserve existing work and run checks relevant to the actual change.
