## 插件市场升级说明

本次发布只收录到 v2 插件市场。v1 已冻结，原地址、索引内容和对应安装包持续保留。旧客户端仍可使用冻结目录中的插件，但不会看到后续的新插件和更新。请升级到支持 v2 目录的 OxideTerm 版本。

## Plugin marketplace upgrade

This release is listed only in the v2 plugin marketplace. v1 is frozen; its original URL, exact contents, and referenced packages remain available. Existing clients can keep using the frozen catalog but will not see subsequent plugins or updates. Upgrade to an OxideTerm version supporting the v2 catalog to receive them.
